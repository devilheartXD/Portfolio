# Stem Files for Console Mixer

วางไฟล์ stem ในโฟลเดอร์นี้ ชื่อต้องตรงตามนี้:

| ไฟล์ | Channel |
|------|---------|
| `beat.mp3`  | BEAT  |
| `bass.mp3`  | BASS  |
| `synth.mp3` | SYNTH |
| `keys.mp3`  | KEYS  |
| `vox.mp3`   | VOX   |
| `fx.mp3`    | FX    |

## ข้อกำหนด
- Format: **MP3** (หรือ WAV/OGG ก็ได้ แต่ต้องแก้ไฟล์ใน index.html ด้วย)
- ทุก stem ต้องมีความยาวเท่ากัน และ loop ได้
- Export จาก Ableton: File → Export Audio/Video → แยก track ทีละ stem

## วิธีใช้
1. วางไฟล์ทั้งหมดในโฟลเดอร์นี้
2. กด ▶ ใน Mixer panel บนเว็บ
3. Fader แต่ละ channel ควบคุม volume ของ stem นั้น
4. กด MU เพื่อ mute channel
